Hello this is where all released maps are kept in case something goes wrong elsewhere. 
To play them you can simply download them and click on the file - this will automatically open minecraft and place the map inside your minecraftWorlds directory. This will make them playable through Minecraft's GUI. Note: you need Minecraft Bedrock edition to be able to play them.
To see the contents of the maps you can change the extensions from .mcworld -> .zip and then you can freely explore what's inside the map folder.
